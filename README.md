# Jagger Docs

Standalone documentation site for [docs.jaggerbrulato.com](https://docs.jaggerbrulato.com) built on the shared [`jagger-ui`](https://github.com/JBoss925/jagger-ui) submodule.

## Development

```bash
git clone --recurse-submodules https://github.com/JBoss925/jagger-docs.git
npm install
npm run dev
```
